# volt-demo-cli

The **single-CLI repo** demo for [volt](https://github.com/khanakia/voltkit): one `main` package at the repo root, bare `vX.Y.Z` tags, workflows and install scripts generated by `volt gen`.

```sh
curl -fsSL https://raw.githubusercontent.com/khanakia/volt-demo-cli/main/install.sh | sh
volt-demo-cli --version
```

Released with `volt release . v0.1.0`. This repo doubles as a regression fixture: volt changes are tested against it.
